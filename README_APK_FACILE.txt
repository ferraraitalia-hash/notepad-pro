# NotePad PRO - APK in 2 click

Hai 2 modi per avere l'APK, scegli quello più facile per te:

## METODO 1 - SENZA INSTALLARE NULLA (GitHub fa tutto)

1. Crea un account gratis su github.com
2. Crea un nuovo repository vuoto (chiamalo notepad-pro)
3. Carica TUTTO il contenuto di questa cartella nel repository (drag & drop)
4. Vai su Actions -> vedrai "Build APK" in esecuzione -> aspetta 2-3 minuti
5. Alla fine clicca su "NotePad-PRO-APK" e scarichi il file app-debug.apk
6. Sul telefono Android: apri il file APK e installa

Fatto!

## METODO 2 - PWABuilder (ancora più veloce, 1 minuto)

1. Vai su www.pwabuilder.com
2. Carica la cartella www su Netlify Drop (https://app.netlify.com/drop) - trascini la cartella www e ottieni un link https
3. Incolla quel link su PWABuilder -> Build -> Android -> Scarica APK

## METODO 3 - Installazione immediata senza APK

Apri www/index.html con Chrome sul telefono -> Menu -> Aggiungi a schermata Home -> avrai l'app.
